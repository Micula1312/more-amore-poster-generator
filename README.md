# More Amore Poster Generator — MVP

Editor web per flyer tipografici 3D.

## Avvio

```bash
npm install
npm run dev
```

## Cosa c'è già

- campi separati: logo, guest, support 1/2, venue, address, date, time
- testo editabile live
- size, position, scale X/Y, rotation X/Z
- depth, bevel, bend
- color, metalness, roughness
- preset Plastic / Chrome / Cream
- preset globali Classic / Chrome / Warp
- export PNG 1080×1350
